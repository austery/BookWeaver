Proposal for "Everything-to-EPUB"

Since the user prefers EPUB quality, we can make the EPUB pipeline the Standard path. Non-EPUB files (PDF/DOCX) get converted to EPUB via Calibre first, then processed by the same logic. This eliminates the "broken format" issue entirely.

My Recommendation: Strategy

A

Unify Translation Logic

Extract the batching, retry, and API calling logic into a standalone TranslationEngine class.

B

EPUB as Universal Format

Prioritize EPUB workflow. Use Calibre to convert other formats to EPUB first to preserve high-fidelity layout.

C

Strict Centralized Config

Refactor all scripts to use a single ConfigManager that handles JSON loading and prompt templating.
